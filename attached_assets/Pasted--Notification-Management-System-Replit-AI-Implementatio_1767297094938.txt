## 🗄️ Database Setup

### Step 1: Create Notification Templates Table

Run the SQL from `notification_db_schema` artifact to create the `notification_templates` table with all 22 default notifications (12 email + 10 SMS).

**Key Fields:**
- `type`: 'email' or 'sms'
- `code`: Unique identifier (e.g., 'booking_confirmation')
- `name`: Display name
- `recipient_type`: 'passenger', 'driver', 'admin', or 'user'
- `subject`: Email subject line (email only)
- `content`: HTML email body (email only)
- `sms_content`: SMS text message (SMS only)
- `available_shortcodes`: Comma-separated list of variables
- `status`: 'active' or 'inactive'

## 🔑 Shortcode System

### Available Shortcodes by Category

**Booking Related:**
- `{booking_id}` - Booking ID number
- `{pickup_location}` - Full pickup address
- `{dropoff_location}` - Full dropoff address
- `{pickup_datetime}` - Full date and time
- `{pickup_time}` - Time only
- `{vehicle_type}` - Vehicle type/category
- `{estimated_fare}` - Price with currency

**User Related:**
- `{passenger_name}` - Passenger full name
- `{passenger_email}` - Passenger email
- `{passenger_phone}` - Passenger phone
- `{driver_name}` - Driver full name
- `{driver_phone}` - Driver phone
- `{user_name}` - Generic user name

**Driver/Vehicle:**
- `{vehicle_model}` - Car model
- `{license_plate}` - License plate number
- `{estimated_arrival}` - ETA text

**System:**
- `{site_name}` - Your site name
- `{site_url}` - Your website URL
- `{current_date}` - Current date
- `{support_email}` - Support email address

### How Shortcodes Work

When sending a notification:
```php
$data = [
    'booking_id' => $booking['id'],
    'passenger_name' => $booking['passenger_name'],
    'pickup_location' => $booking['pickup_address']
];

$notifier->sendEmail('booking_confirmation', $email, $name, $data);
```

The system automatically replaces `{booking_id}` with the actual ID, `{passenger_name}` with the name, etc.

## 🔒 Security Considerations

### Implement These Safeguards

1. **Admin Authentication**
   ```php
   if (!isset($_SESSION['user_id']) || $_SESSION['role'] !== 'admin') {
       header('Location: ../login.php');
       exit;
   }
   ```

2. **Input Validation**
   - Validate email addresses
   - Validate phone numbers (international format)
   - Sanitize all user inputs
   - Validate code uniqueness

3. **SQL Injection Prevention**
   - Use prepared statements (PDO)
   - Never concatenate user input into queries

4. **XSS Prevention**
   - Use `htmlspecialchars()` when displaying user data
   - Sanitize WYSIWYG content (TinyMCE does this automatically)

5. **CSRF Protection**
   - Add CSRF tokens to forms
   - Validate tokens on submission

## 🐛 Troubleshooting

### Common Issues

**Email not sending:**
- Check SMTP credentials
- Verify firewall allows SMTP port
- Test with a simple script first
- Check error logs

**SMS not sending:**
- Verify phone number format (+country code)
- Check Twilio account balance
- Verify phone number is verified (sandbox mode)
- Check API credentials

**Shortcodes not replacing:**
- Ensure exact match: `{booking_id}` not `{ booking_id }`
- Verify data array has correct keys
- Check for typos in shortcode names

**WYSIWYG not loading:**
- Check internet connection (CDN)
- Verify script tag is in `<head>` or before init
- Check browser console for errors

## 📚 Usage Examples

### Sending Booking Confirmation

```php
require_once 'includes/NotificationHelper.php';
$notifier = new NotificationHelper($pdo);

// Prepare booking data
$bookingData = [
    'id' => $bookingId,
    'passenger_name' => $passenger['name'],
    'passenger_email' => $passenger['email'],
    'passenger_phone' => $passenger['phone'],
    'pickup_location' => $booking['pickup_address'],
    'dropoff_location' => $booking['dropoff_address'],
    'pickup_datetime' => $booking['pickup_time'],
    'vehicle_type' => $booking['vehicle_type'],
    'estimated_fare' => $booking['fare']
];

// Send both email and SMS
$notifier->sendBookingConfirmation($bookingData);
```

### Sending Custom Notification

```php
// Custom email
$notifier->sendEmail('booking_reminder', 'user@example.com', 'John Doe', [
    'booking_id' => 12345,
    'pickup_time' => '10:00 AM',
    'pickup_location' => '123 Main St'
]);

// Custom SMS
$notifier->sendSMS('sms_booking_reminder', '+1234567890', [
    'booking_id' => 12345,
    'pickup_time' => '10:00 AM'
]);
```

### Driver Assignment Flow

```php
// When assigning driver to booking
$notifier->notifyDriverAssignment($bookingData, $driverData);

// When driver accepts and starts heading
$notifier->notifyDriverOnTheWay($bookingData, $driverData, '5 mins');

// When driver arrives
$data = [
    'passenger_name' => $booking['passenger_name'],
    'driver_name' => $driver['name'],
    'driver_phone' => $driver['phone'],
    'vehicle_model' => $driver['vehicle'],
    'license_plate' => $driver['plate']
];
$notifier->sendEmail('driver_arrived', $passenger['email'], $passenger['name'], $data);
$notifier->sendSMS('sms_driver_arrived', $passenger['phone'], $data);
```
